# Changelog

## 1.0.0 — 2026-11-02

- Publish three independently installable HMI skills under MIT.
- Add concise discovery descriptions, Codex interface metadata, installation
  instructions, official-format validation and helper tests.
- Remove workstation-specific research dependencies and downgrade citations
  whose original research is not included; retain public source references.
- Clarify stopping versus saving, active versus acknowledged alarms, process-
  dependent display cadence, physical versus CSS sizing, and kiosk accessibility.
- Include activation and behavioral evaluation cases; automated checks do not
  claim model-based evaluation or physical-machine validation.
- Improve helper input errors and CSS/device-pixel reporting, with regression tests.
